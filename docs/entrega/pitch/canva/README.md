# Importar no Canva

Há duas formas de levar a apresentação para o Canva.

## Opção recomendada — apresentação editável

Importe o arquivo [PITCH_AI_GLASSES_BRASIL.pptx](../PITCH_AI_GLASSES_BRASIL.pptx). O formato *PowerPoint Open XML Presentation* (PPTX) preserva textos e elementos editáveis sempre que o Canva reconhece as fontes e os recursos usados.

No Canva:

1. abra **Criar um design**;
2. selecione **Importar arquivo**;
3. envie o arquivo PPTX;
4. confira fontes, quebras de linha e links após a conversão.

## Opção de fidelidade visual — imagens

A pasta [slides/](slides/) contém uma imagem por página em 1920×1080 no formato *Portable Network Graphics* (PNG). Use essas imagens como fundo de cada página quando for mais importante preservar exatamente o layout.

Nesse modo, os textos não ficam editáveis. Para alterar conteúdo, edite o PPTX ou o gerador e exporte novamente.

## Referência

O arquivo [PITCH_AI_GLASSES_BRASIL.pdf](../PITCH_AI_GLASSES_BRASIL.pdf), em *Portable Document Format* (PDF), serve para comparar a importação com o resultado aprovado.
